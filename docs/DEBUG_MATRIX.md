## P1: 今回追加確認したいケース

| 領域 | シナリオ | 期待結果 |
|---|---|---|
| localStorage | 壊れたJSONが保存されている | 起動不能にならず安全に初期化/無視 |
| localStorage | 古い形式・項目欠損 | 可能な範囲で扱うか、安全に無視 |
| 店舗候補 | 同名店舗を複数回追加 | 仕様どおり重複を扱う |
| 店舗候補 | 空文字/空白だけ追加 | 無効入力として扱う |
| 店舗候補 | 非常に長い店名 | UIが致命的に崩れない |
| 連打 | ルーレットボタン連打 | 多重実行・状態破損を起こさない |
| 状態遷移 | 抽選中に画面切替 | 状態が破損しない |
| 状態遷移 | 結果後に条件変更 | 古い結果を誤表示しない |
| API | 0件レスポンス | 0件状態を明示し条件を勝手に変更しない |
| API | 4xx/5xx | アプリが落ちず、再試行可能な説明を出す |
| API | 不正JSON/欠損フィールド | アプリが落ちない |
| API | 遅延レスポンス | 多重送信や不整合を起こさない |
| Google Maps | 外部リンク生成 | 条件・場所が正しく反映される |
| アクセシビリティ | キーボード操作 | 主要操作に到達できる |
| モバイル | 320〜390px幅 | 主要CTAが画面外/重なりで操作不能にならない |
| モバイル | ソフトキーボード表示 | 入力/CTAが操作不能にならない |

## P2: 今後E2E化する候補

- 初回起動 → 料理選択 → 抽選 → 決定 → 履歴確認
- みんなで → 店を決める → 2店舗追加 → 抽選 → 保存
- 保存済み → 再抽選
- 道中で探す → 条件入力 → 店舗検索 → 候補から抽選
- リロード後の保存/履歴復元
- API失敗後の再試行

## 判定

- **PASS**: 仕様どおりで再現性あり
- **FAIL**: 仕様と異なる
- **BLOCKED**: 外部依存などで確認不能
- **NOT TESTED**: 未確認

Critical / High の FAIL が残っている状態ではデバッグ完了にしない。
